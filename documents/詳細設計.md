# 詳細設計

## 実装構成

* `app.py`: Flask の画面、API、SQLite スキーマ、認証、OTP 取得を担当する。
* `worker.py`: POP/IMAP 接続、メールの正規化、重複排除、OTP 抽出を担当する。
* `templates/`: Flask の管理画面テンプレートである。

## API キー認証

発行時に UUID v4 を生成し、Werkzeug のパスワードハッシュを `auth.apikey` に保存する。認証時は登録済みハッシュへ `check_password_hash` を適用する。平文キーは DB、ログ、一覧へ保存しない。

## OTP 取得の排他制御

OTP 取得は SQLite の `BEGIN IMMEDIATE` で開始する。`used=0` かつ `otp.time + rules.expiration > 現在UTC時刻` の最新行を取得し、同一トランザクションで `used=1` に更新する。その後に `200` を返すため、同じ OTP を同時に二重返却しない。

## メールデータの最小化

ワーカーはメール本文全体をメモリー内だけで扱う。DB には本文先頭 15 文字だけを `messages.body_head` に保存する。本文全体は OTP 抽出と `Message-ID` 不在時の SHA-256 算出後に保持しない。

## 制限事項

メールパスワードは利用者の確定仕様により平文で DB へ保存する。このため DB ファイルをアプリケーション実行ユーザー以外が読み取れないように運用する。メール受信・認証失敗はログ保存しない。
