# メール OTP プロキシ仕様書

## 目的

POP または IMAP で受信したメールから OTP を抽出し、認証済み Web API で自動化プロジェクトへ提供する。Python と Flask を使用する。

## 画面と認証

* `/index` はアカウント、ルール、受信メール、新着 OTP を表示する。
* `/config` 以下は管理画面である。起動時に `GUI_PASSWD` を読み込み、未設定ならランダムな値を CUI に表示する。
* `/config/mailAccounts` はアカウントの登録・編集・削除と、全アカウント共通のメール確認間隔を設定する。
* `/config/extractRules` は抽出ルールの登録・編集・削除を行う。不正な正規表現は登録しない。
* `/config/api` は UUID v4 の API キーを発行する。平文キーの表示は発行時だけである。

## データ

`accounts` は ID、メールアドレス、ログイン ID、平文パスワード、サーバー、プロトコル、暗号化方式、ポートを保存する。`rules` は送信元・件名・本文抽出の正規表現と有効期限を保存する。`otp` は受信時刻、使用済み状態、アカウント、ルール、OTP を保存する。`auth` は API キーのハッシュ値と説明を保存する。

`messages` は画面表示用に送信元、宛先、受信時刻、件名、本文先頭 15 文字だけを保存する。本文全体は保存しない。`settings` の `mail_check_seconds` は全アカウント共通の取得間隔である。

## メール処理

1. ワーカーは設定された間隔で全アカウントを巡回する。
2. メールヘッダの宣言に従い文字列を復号し、内部では UTF-8 を用いる。文字化けする送信元は非対応とする。
3. `Message-ID` があればそれを識別子にする。なければ UTF-8 本文全体の SHA-256 ハッシュ値を識別子にする。
4. アカウント ID と識別子が既に存在するメールは処理しない。
5. 送信元と件名がルールに一致した場合だけ本文を検索し、最初の OTP 一件を保存する。複数 OTP は非対応とする。

## API

すべての API は `Authorization: Bearer <apikey>` を必要とする。不正または未指定なら `401` を返す。

* `GET /api/v1` は正しい認証で `200` と `{"status":"ok"}` を返す。
* `GET /api/v1/getOTP?accounts=<account_id>&rules=<rule_id>` は未使用かつメール受信時刻から有効期限内の最新 OTP を返す。
* OTP があれば `200` と `{"accounts":"...","rules":1,"otp":"123-456"}` を返し、直後に使用済みにする。
* OTP がなければ `202` と `{"accounts":"...","rules":1,"otp":null}` を返す。
* 存在しないアカウントまたはルールは `404`、不正なパラメータは `400` を返す。
